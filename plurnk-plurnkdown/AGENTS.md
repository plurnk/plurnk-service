# plurnk-plurnkdown

`@plurnk/plurnk-plurnkdown` defines and validates the structured Markdown format
used for model packets.

`SPEC.md` describes the format. Keep the renderer and linter aligned with
that document and test both valid output and actionable diagnostics. Formatting
policy belongs here only when it affects machine interpretation, stable packet
layout, or interoperability; ordinary prose style does not.
