# @plurnk/plurnk-parser — SPEC

## §parser-build Package boundary, build, and Heredoc Code Mode parser (RENO)

`@plurnk/plurnk-parser` implements the PLURNK Heredoc Code Mode language and Reflective Emission Normalization (RENO) specified by `@plurnk/plurnk-contracts`. It owns `CodeMode`, `ChunkScanner`, `CallExpressionParser`, `OptionCoercion`, `StatementLowering`, `CodeSerializer`, `NativeEnvelopes`, `XmlEnvelopes`, `HeredocSyntax`, `TargetSyntax`, `ScopeSyntax`, `MatcherSyntax`, the `PlurnkParser` tier entry points (`parse`, `parseStatements`, `lowerToolCall`, `stringify`), `parsePath`, and the `plurnk-parser` CLI.

- **Consumer boundary**: Only the service's execution path (`plurnk-core`, `plurnk-acp`, `plurnk-mcp`, `plurnk-execs`) imports `@plurnk/plurnk-parser`. `@plurnk/plurnk-contracts` declares no dependency on `@plurnk/plurnk-parser`, `xpath`, or `json-p3`.
- **Heredoc Code Mode parsing, RENO admission, and reflective serialization**: `ChunkScanner`, `NativeEnvelopes`, and `XmlEnvelopes` partition source into top-level statement chunks and outside prose while deterministically transducing foreign native tool-call envelopes; `CallExpressionParser`, `OptionCoercion`, and `StatementLowering` lower declarative calls (`PlurnkParser.parse`, `PlurnkParser.parseStatements`) and structured tool invocations (`PlurnkParser.lowerToolCall(service, tool, args, options)`) to `plurnk.<tool>(...)` and `<server>.<tool>(...)` through one shared `dispatchCall` pipeline into typed `PlurnkStatement` AST nodes; and `CodeSerializer` serializes AST statements back into canonical unwrapped Heredoc Code Mode syntax via `PlurnkParser.stringify` for `emission` / `emission-history` (`assistant` turn) reflection.
- **Build and installation gate**: `npm run build` compiles the package cleanly into `dist/`. `npm run test:installation` packs both `@plurnk/plurnk-contracts` and `@plurnk/plurnk-parser` tarballs, installs them into a clean consumer, and verifies all entry points, `parsePath`, the CLI, and browser-bundle compatibility.
